## 🔴 Critical – Missing Server API Endpoints

The following endpoints are called by the frontend but have **no handler** in [`apiPlugin.ts`](../src/server/apiPlugin.ts). These will result in **404 errors at runtime**.

### 1. Password Reset Endpoint

| Detail | Value |
|---|---|
| **Frontend call** | `PUT /api/users/:id/reset-password` |
| **Called from** | `appStore.ts` → `resetUserPassword()` |
| **Impact** | Admins cannot reset a user's password |
| **Action required** | Add `app.put('/api/users/:id/reset-password', ...)` handler to `apiPlugin.ts` using `supabaseAdmin.auth.admin.updateUserById()` |

### 2. Schedule PLU Change – Create

| Detail | Value |
|---|---|
| **Frontend call** | `POST /api/plu_scheduled_changes` |
| **Called from** | `appStore.ts` → `schedulePluChange()` |
| **Impact** | Scheduled price/PLU changes cannot be created |
| **Action required** | Add POST handler that inserts into `plu_scheduled_changes` table |

### 3. Scheduled PLU Changes – Fetch Due

| Detail | Value |
|---|---|
| **Frontend call** | `GET /api/plu_scheduled_changes/due` |
| **Called from** | `appStore.ts` → `applyDueScheduledChanges()` |
| **Impact** | System cannot check for due scheduled changes |
| **Action required** | Add GET handler that queries `plu_scheduled_changes` where `scheduled_at <= now()` and `applied_at IS NULL` |

### 4. Scheduled PLU Changes – Mark Applied

| Detail | Value |
|---|---|
| **Frontend call** | `PUT /api/plu_scheduled_changes/:id/applied` |
| **Called from** | `appStore.ts` → `applyDueScheduledChanges()` |
| **Impact** | Applied changes cannot be marked as complete, leading to duplicate applications |
| **Action required** | Add PUT handler that sets `applied_at = now()` on the given record |

## 🔴 Critical – Vercel Production Route Gaps

[`vercel.json`](../vercel.json) only defines rewrites for `/api/users/*`. All other API endpoints work in local dev (via the Vite plugin) but will **fail in production** on Vercel.

### Missing Vercel Serverless Functions

| Endpoint Group | Routes Affected |
|---|---|
| **PLU Categories** | `POST /api/plu_categories/create`, `PUT /api/plu_categories/:id`, `DELETE /api/plu_categories/:id` |
| **PLU** | `POST /api/plu/create`, `PUT /api/plu/:id`, `DELETE /api/plu/:id` |
| **Logbook** | `GET /api/logbook`, `POST /api/logbook/create` |
| **Scheduled Changes** | `POST /api/plu_scheduled_changes`, `GET /api/plu_scheduled_changes/due`, `PUT /api/plu_scheduled_changes/:id/applied` |
| **Password Reset** | `PUT /api/users/:id/reset-password` |

**Action required:** Create corresponding serverless functions under `api/` and add rewrite rules to `vercel.json` for each endpoint group.

| Detail | Value |
|---|---|
